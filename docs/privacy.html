🇳🇵 Nepal Pulse — Privacy Policy

Effective date: May 6, 2026  |  Last updated: May 6, 2026

Nepal Pulse ("we", "our", "the Page") is an automated news aggregation service that curates and publishes Nepal-related news to our Facebook Page. This Privacy Policy explains how our publishing automation application ("the App") interacts with Facebook data.

1. What the App Does

The Nepal Pulse App is a private, automated tool used solely by the Page administrator to publish news posts to the Nepal Pulse Facebook Page. It is not a consumer-facing application and does not collect data from any Facebook user other than the Page administrator.

2. Data We Access

The App accesses the following Facebook data, exclusively for the purpose of publishing posts to our own Page:

  • Facebook Page Access Token — used to authenticate API calls to post content on behalf of the Nepal Pulse Page. This token is stored securely on the administrator's private server and is never shared with third parties.
  • Page posts — the App reads its own previously published posts to avoid duplicate publishing.

The App does not access, collect, or store any personal data from Facebook users, followers, or visitors to the Nepal Pulse Page.

3. How We Use Facebook Data

Facebook data accessed by the App is used solely to:

  • Publish news articles, official statements, and editorial content to the Nepal Pulse Facebook Page.
  • Verify that content has not already been posted.

We do not use Facebook data for advertising, profiling, analytics, or any purpose other than the above.

4. Data Storage and Security

The Page Access Token is stored in an encrypted environment configuration file on the administrator's server. It is not logged, transmitted, or accessible to any third party. No user data is stored in any database or log file.

5. Third-Party Data Sharing

We do not sell, rent, or share any Facebook data with third parties.

6. Children's Privacy

The App does not collect any data from users of any age. The Nepal Pulse Facebook Page is intended for general audiences.

7. Changes to This Policy

We may update this Privacy Policy from time to time. The "Last updated" date at the top of this page will reflect any changes. Continued use of the Nepal Pulse Facebook Page constitutes acceptance of the updated policy.
